# Guided Website Uses Full-page Visual Questions

The Guided Website workflow uses a full-page comparison as its primary way to capture preferences that the active Framework cannot determine. Each step keeps the Framework foundations and content stable, changes one composition or voice dimension where practical, and asks the person to choose directly from rendered outcomes. This was promoted from the isolated `prototype/guided-website-workflow` experiment after Variant A was selected because the whole-page view made the consequence of each choice easier to judge.

Compact visual boards remain a supporting pattern for quick questions inside the workflow, not the primary authoring surface. They may summarize or revisit one bounded decision, but they must not replace the full-page Preview when a choice affects page-level composition.

The workflow records explicit selections, skips, and approved examples as project evidence. It does not mutate Active Framework preferences automatically. Promotion into reusable Component, Section, or Page Guidance requires a separate reviewed decision, preserving ADRs 0005, 0006, and 0008.

Portable output is one self-contained Markdown context containing the project brief, approved voice evidence, Framework provenance, and the exact generated `context.md` for the Active Framework. The semantic content hash is labeled informational rather than treated as an exact artifact digest or certification.

## Reference basis

Research snapshot: 2026-07-31. The production comparisons extract transferable composition mechanics from live first-party pages; they do not reproduce protected branding, copy, imagery, or site-specific CSS.

- `https://linear.app`: product-led hierarchy, restrained navigation, and a dominant interface artifact.
- `https://press.stripe.com`: editorial composition, one memorable focal object, and deliberate negative space.
- `https://www.apple.com`: campaign pacing, one message per visual field, and large product moments.
- `https://www.theverge.com`: dense editorial scanning, asymmetry, and concurrent reading paths.
- `https://mailchimp.com`: expressive campaign voice, high-contrast headline treatment, and human promotional framing.
- `https://www.gov.uk`: utility-first copy, flat service surfaces, and explicit task hierarchy.

These observations map to four controlled decisions while content and Framework foundations remain stable: Product-led versus Editorial-led composition, Campaign pace versus Editorial scan density, Quiet canvas versus Layered workspace surfaces, and Utility-first versus Expressive campaign voice.
